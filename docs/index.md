# VERITAS-AI

VERITAS-AI examines a narrow but important question. Once an organisation deploys an AI-enabled security system, what evidence would show that the capability still behaves within its accepted envelope?

The repository contains a laboratory proof of concept. A synthetic intrusion classifier acts as the system under assurance. The monitoring layer records data quality, distribution change, labelled performance when labels are available, execution latency, and cryptographic integrity. It then produces an advisory outcome for an operator.

The current evidence is consistent with TRL 3 only. No operational organisation, external partner, or representative cyber range has validated this release.
